## Rules

1. Before starting a task, read this file and set its status to `in progress (<agent>, <date time>)`. When it's
   done, set `done` with one line: the result and the files changed. Then append a line to the Log.
2. **File ownership.** Neither agent edits the other's files; ask in the Log instead.
   - LOCAL owns: `services/**` (except `services/model-api/analysis/phase*`), `apps/`, `sdk/`, `extension/`,
     `packages/`, `scripts/`, the compose files, `RUN_LOG.md`, `TODO.md`, `HANDOFF.md`, the manuscript and pages.
   - CLOUD owns: `services/model-api/analysis/phase*/`, `artifacts/phase*/`, `PREREGISTRATION_L*` drafts and
     `docs/recovery/`.
   - Both edit this file, but only their own task rows plus appended Log lines.
3. **Git is LOCAL only.** Commit and push only after the OWNER says yes. Before every commit, run
   `git diff --cached --name-only` and make sure no `*.db*`, `*.bak`, per-user models or datasets are staged.
   Commit messages never mention Anthropic, Claude or AI tooling.
4. **Reviews don't block.** CLOUD reviews LOCAL's code tasks in parallel. If CLOUD logs a problem, it is fixed
   before the commit.
5. Nothing confirmatory runs before its pre-registration is approved by the OWNER and hashed.
