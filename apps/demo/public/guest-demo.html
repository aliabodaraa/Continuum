New note

A completely ordinary app. It has no idea how continuous auth works — it just dropped in one script.

This page's entire integration is one script tag pointing at Continuum's gateway, with data-identity-url so the SDK identifies the logged-in user from this app's session — no CA endpoints, no identity code. The floating Guard panel lets you toggle keystroke and mouse monitoring on/off. Save is a sensitive action: it attaches the SDK's signed risk token (Continuum.riskHeader()) and the server only allows it when your live behavior is genuine — otherwise it's blocked (403).
