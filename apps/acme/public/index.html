Secure note

Acme runs on its own origin (:4200) with its own backend. The only Continuum code here is one script tag — everything else (onboarding, passkey, verification) is provided by the SDK.

Save is enforced by Acme's own backend using Continuum's signed verdict: guard.requireTrusted. If your live behavior looks suspicious it returns 403 and the SDK asks for a passkey — Acme itself decides nothing about trust.
